ATLANTIDA RESORT — сайт-визитка

Файлы:
- index.html — структура и тексты сайта
- style.css — дизайн, адаптивность, анимации
- script.js — мобильное меню, галерея на весь экран, анимации появления, форма
- assets/ — фотографии, которые вы загрузили

Как проверить:
1. Распакуйте архив.
2. Откройте папку atlantida-resort.
3. Откройте index.html в браузере. Для наиболее корректной проверки можно использовать VS Code + Live Server.

Как загрузить на хостинг:
1. В панели хостинга откройте файловый менеджер сайта и папку сайта (часто это www или public_html — ориентируйтесь на папку, где уже лежит текущий index.html).
2. Сначала сохраните копию старых файлов.
3. Загрузите index.html, style.css, script.js и папку assets целиком в корень сайта, чтобы index.html лежал рядом с style.css и script.js.
4. Откройте сайт и обновите страницу без кэша.

Важно:
- Форма сейчас демонстрационная и ничего никуда не отправляет. Для реальных бронирований подключим WhatsApp/Telegram/почту или серверную обработку.
- Контакты, цены, адрес и расписание не выдумывались; их можно добавить после того, как вы пришлёте точные данные.
- Google Fonts требуют подключения к интернету, но при недоступности шрифтов сайт использует системные запасные шрифты.
